TALAS · PINKADELIC 45001

Dylan prépare l’audit avec Boulon.

Embarque, ramasse les fiches terrain, porte les objets et affronte les patrons les plus indigestes.
Sept chapitres. Douze zones. Tes choix ont des conséquences.

Jouer ouvre le plein écran. Échap permet d’en sortir.

La progression est conservée dans ce navigateur.

Commandes

Q/D ou gauche/droite : suivre le parcours
Espace : sauter · relâcher puis appuyer : second saut · maintenir : ralentir la chute
Ctrl, S ou flèche bas : s’accroupir
E ou flèche haut : parler / ouvrir une porte · 1–4 : répondre · Entrée : poursuivre
R : prendre ou déposer · C : cachette avec ton butin
F : frapper / lancer l’objet porté
H : revenir au domaine · M : carnet · L : documents · Échap : menu

Mobile : joystick à gauche pour suivre le parcours et s’accroupir · Croix saut · Rond parler / ouvrir / se cacher / continuer un dialogue · Triangle prendre / déposer · L1 frapper / lancer · MENU pause. Ce sont les boutons du jeu d’origine.
