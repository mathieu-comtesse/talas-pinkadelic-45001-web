# Talas · Pinkadelic 45001 — navigateur

[Jouer dans le navigateur](https://mathieu-comtesse.github.io/talas-pinkadelic-45001-web/)

Clique sur **Jouer**, puis **Commencer la campagne**. Utilise le clavier et le bouton plein écran. La progression est conservée dans le navigateur.

Ce dépôt contient uniquement la compilation Web jouable. Les sources Unity/Blender et la version Windows restent dans le [dépôt séparé](https://github.com/mathieu-comtesse/talas-pinkadelic-45001).

Version 0.2.0-web : 12 zones, personnages Talas et 74 évaluations ISO 45001. L’IA PSX complète, les plateformes mobiles et la fidélité intégrale au pixel près restent à terminer.
