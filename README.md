# Talas · Pinkadelic 45001 — navigateur

[Jouer dans le navigateur](https://mathieu-comtesse.github.io/talas-pinkadelic-45001-web/)

Clique sur **Jouer** : le jeu passe en plein écran. **Échap** permet d'en sortir. La progression est conservée dans ce navigateur.

Version **0.3.0-web** : 10 personnages Talas remodelés et animés avec les courbes Pinky, course et freinage à 30 Hz, accroupissement, sauts et transport d'objet. Caméra perspective et affichage adaptés à toute la surface de l'écran sans étirer les personnages. Les 12 zones et les 74 évaluations ISO 45001 sont conservées.

Q/D ou flèches gauche/droite : courir ; Z/S : profondeur ; Espace : saut ; Ctrl ou flèche bas : accroupi ; E : parler ; R : prendre/déposer ; M : carnet ; L : documents.

Ce dépôt contient la compilation Web. Les sources Unity/Blender et les preuves de validation sont dans le [dépôt séparé](https://github.com/mathieu-comtesse/talas-pinkadelic-45001). La version Windows v0.1.0 conserve son ancien rendu.

Le transfert des animations et des paramètres de déplacement est vérifié. Les collisions contextuelles PSX, l'IA complète, la queue et les doigts Pinky ne sont pas reproduits à l'identique. Les smartphones ne disposent pas encore de commandes tactiles.
